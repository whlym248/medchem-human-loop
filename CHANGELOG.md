# Changelog

## 0.2.0 — 2026-10-04

- Added a local case schema and lexical retrieval with source/review fields, synthetic isolation, and an explicitly empty real-literature corpus.
- Added four constrained single-site aromatic graph edits with retained atom mapping, fixed-region checks and optional RDKit tests. This is not a general molecular generator or synthesis assessment.
- Added transparent route suggestions; unsupported diffusion remains deferred and no trained policy is claimed.
- Connected edit proposals to evidence shells with missing metrics, then to frozen HTML/JSON review packets, human decision history and identity-checked round linkage.
- Added an HPC agent entry point, deployment guide, incident review, private handoff template and a bounded inspection probe. The new probe has not been tested on a live school node.
- Expanded lightweight tests and CI for file contracts, graph edits and synthetic round demonstrations; no MD or prediction execution is part of these checks.

Diffusion, curated real case content, integrated structure preparation/docking/ADMET/MD orchestration and scientifically validated risk-benefit recommendations remain future work.

## 0.1.0 — 2026-10-03

- Published the human-in-the-loop molecular optimization design with its implementation status, evidence boundaries and roadmap.
- Released existing MD execution, pilot review and production trajectory analysis tools with explicit preparation contracts.
- Added a standard-library evidence assembler and a clearly labeled synthetic example.
- Included an optional reference interface for fixed-pose Vina/Vinardo scoring and pretrained ADMET-AI inference with user-supplied inputs and installed weights.
- Added lightweight tests and CI that do not simulate molecular dynamics or call prediction services.
- Included author information, citation metadata and the MIT license for original code and documentation.

This initial public release does not include a trained optimization policy, diffusion generator, live literature service, bundled docking engine, ADMET model weights, prepared molecular systems or raw experimental/simulation datasets.
