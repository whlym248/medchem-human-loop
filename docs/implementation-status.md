# 实现状态

此表说明 v0.2 第一批模块的边界。**有设计文字、曾经手动执行过某步骤，以及已有可复用自动实现，是三种不同状态。** 本版增加可运行的案例、有限编辑、路线和审阅模块，不代表完整自动药物优化已经实现。后续顺序见 [开发计划](development-plan.md)。

## 如何理解“可运行代码”

指模块提供明确入口和输入约定，不代表对任意靶点、任意软件版本或任意输入都已验证。轻量自动化测试与合成示例不启动 MD，不能替代使用者对计算环境、参数化和科学结论的核查。实际运行环境、测试覆盖和依赖跳过项见 [验证记录](../tests/VALIDATION.md)。

本地案例库检索通过，只说明所提供的记录满足格式和检索条件。字段 `reviewed` 是自报审核声明，不是论文真实性认证。有限编辑的价态和图约束检查通过，也不证明候选可合成、有活性或安全。轮次哈希链可检测部分意外改动，不能代替身份认证、数字签名或不可篡改审计。

新增模块的使用边界分别见 [案例库](case-library.md)、[有限编辑](local-edits.md)、[路线规则](route-selection.md) 与 [人工审阅轮次](review-rounds.md)。

MD 代码源自研究执行工具。公开版本对路径与分发边界进行整理，具体源文件与改动见 `scripts/SOURCE_PROVENANCE.json`。换体系时应审查配体映射、关注残基、蛋白对齐选择、质子化以及模型假设。

固定姿态/ADMET 参考工具同样来自此前实际执行过的脚本，但这次公开适配只检查语法及 CLI，没有重跑评分或推理。它与开箱可运行的合成示例不同，需要已安装环境、可信权重和用户自行准备的匹配输入；详见 [该工具 README](../extras/fixed_pose_admet/README.md)。

## 不应如何描述本版本

不要写成“已训练的药物发现 AI”“全自动强化学习分子优化平台”“已证明提高亲和力”或“已验证安全性”。准确表述为：**人类参与优化工作流的第一批可运行模块，包含本地案例检索、有限规则编辑、透明路线建议、证据审阅与已有计算工具；真实语料、完整计算连接和科学验证仍待补充。**
