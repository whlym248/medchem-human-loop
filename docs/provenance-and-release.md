# 公开范围、来源与许可

## 本仓库公开什么

- whlym提出的人类参与分子优化 workflow 及其实现边界。
- 本项目编写、整理的 MD 执行、技术质量检查、轨迹分析与证据导出工具。
- 来自此前研究复核脚本的可选固定姿态评分与预训练 ADMET-AI 参考接口；其公开适配只做语法与 CLI 检查，未重新执行模型推理。
- 人工构造的合成证据示例与不运行 MD 的轻量测试。

工作流构思、计算执行、分析和代码准备使用 AI 辅助。AI 辅助不替代对代码、来源或结论的责任；已实现能力和后续设想分别列于 [实现状态](implementation-status.md)。

## 不随本次发布分发的材料

真实研究系统、轨迹、完整原始数据、模型权重、第三方论文全文、内部交接资料、账号凭据和计算资源配置不属于本次公开包。依赖工具可由使用者依各自许可安装；需要重现某项研究时，还必须有合法且匹配的输入数据。

因此，仓库可复现的是公开示例的软件行为和所提供的工具接口，不能仅凭克隆仓库就重现某个未公开研究结果。

## 原创文件与第三方组件

原创代码与文档按仓库根目录的 MIT License 发布。使用和再分发时保留所要求的版权与许可声明。欢迎在研究引用中使用 `CITATION.cff`；引用建议不增加 MIT 之外的限制。

OpenMM、NumPy、MDTraj、Matplotlib、RDKit、AutoDock Vina、ADMET-AI 及其模型依赖由各自项目维护者提供，其代码、名称和许可仍归各自项目。调用模型或未来接入生成模型、案例库时，应单独记录软件版本、模型版本、数据来源与许可；本仓库许可证不自动覆盖这些内容。

## 源码来源记录

`scripts/SOURCE_PROVENANCE.json` 记录整理的脚本来源指纹及公开调整；`scripts/README.md` 说明参数与输入约定。来源记录用于追踪代码版本，不用于宣称所有历史研究结果已公开、已独立复核或已获实验验证。

用户自己的数据与结果应分开保存，避免将运行目录、原始轨迹、环境、令牌或个人路径纳入公开提交。版本化小型方法配置与公开许可示例即可；大体积或受限材料应另行管理。
