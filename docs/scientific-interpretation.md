# 科学解释与报告约定

本项目将计算观察、模型预测、方法假设和研究结论分开记录。这有助于使用者看清证据能支持到哪一步。

## 结构和对接

同一名称不保证同一分子：立体化学、电荷、质子化和盐型会影响计算。蛋白的突变、缺失区、重建和残基编号也应记录。只有比较条件明确时，分数差异才具有可讨论的意义。

对接 pose 及接触距离可以形成结合假说。它们无法单独定位亲和力的“根本原因”，也不能直接给出结合自由能、抑制常数或体内效果。较多氢键和较短距离都不必然带来更强结合。

## 技术质量与科学验证

技术 pilot 用于发现非有限能量、不合理温度或密度、明显几何异常及运行问题。短测试末帧通过几何筛查不代表整段轨迹不存在异常；宽松工程阈值不等于统计平衡标准。

`check_pilot_quality.py` 输出报告；`run_md_v2.py review` 记录显式审阅决定。这两件事都不等于验证了结合机制或药理活性。

## 轨迹分析默认判据

分析脚本对保留帧进行周期性边界处理，将蛋白 N/CA/C 对齐到准备后的输入结构，并计算蛋白骨架和配体重原子 RMSD。配体 RMSD 使用固定原子身份，未进行对称等价校正；柔性区域会影响全局蛋白拟合。

默认重原子接触阈值为 **4.0 Å**。直接 N/O 氢键同时要求：

- 供体—受体距离 ≤ **3.5 Å**；
- 氢—受体距离 ≤ **2.5 Å**；
- 供体—氢—受体角 ≥ **135°**。

判定需要显式氢、正确的化学角色和实际质子化状态。水桥、含硫氢键、芳香相互作用、去溶剂化和自由能不在该最小分析的覆盖范围内。CLI 可调整阈值，报告必须保留实际采用值。

占有率是保留采样帧中的比例，帧之间相关，不能把每帧当成独立实验重复。一个原子对的占有率与一个残基上多个原子对的并集占有率不同；后者不能把前者简单相加。

## MD 比较的边界

低 RMSD、接触持续或某氢键高占有率，均不能直接推出亲和力更高。单个随机种子的短轨迹不足以证明收敛、优化成功或双靶功能。应结合独立重复、适当长度、不同起点、统计不确定性和实验依据设计后续验证。

起点若来自不同 docking 方案、不同构建体或不同质子化状态，应明确标注这一混杂因素。母药与候选并非仅因用了同一脚本就自动可比。

## 续跑和未完成数据

中断后的新尝试可能覆盖旧轨迹尾部。分析必须遵循 `segment_manifest.json`，读取每段允许的配对 CSV/DCD 前缀并核对输入与运行身份；不要直接拼接完整 DCD。

默认要求完成状态。显式使用 `--allow-incomplete` 得到的结果是**未完整快照**，应标注覆盖长度和读取时点，不能替代最终分析。历史快照不证明当前任务仍在运行或已经完成。

## ADMET 与预训练模型

分别保留属性名称、单位、输出尺度、模型和版本、输入结构身份，以及适用域或校准信息。分类分数不能直接写作毒性发生百分比；模型间不同尺度也不能直接相加。

预训练电荷模型的估计结果应标记为该模型的预测，不能写成新执行了对应量子化学或 AM1-BCC 计算。外部模型的许可与限制应单独遵守。

## 推荐的结论措辞

| 观察 | 合适的表述 |
|---|---|
| 某接触在保留帧中频繁出现 | “在所分析的该次轨迹中，该接触具有较高占有率。” |
| 某候选 docking 分数较好 | “在该输入与评分协议下得到较有利分数，需进一步核查。” |
| ADMET 输出发生变化 | “模型预测输出变化；其药理意义取决于模型校准、适用域与实验验证。” |
| 技术 pilot 无关键异常 | “技术筛查及审阅支持进入限定的后续计算，不代表科学假说成立。” |
| 数据尚缺失 | “未验证 / 未提供”，保留空值和原因，不以零或估算结果填充。 |
